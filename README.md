# 宝可梦对战捕捉（浏览器原型）

选地图 → 对战 → 滑动丢球捕捉。初始宝可梦为炎兔儿。

## 运行

```bash
# 任意静态服务器均可，例如：
python3 -m http.server 9456 --bind 127.0.0.1
```

浏览器打开 `http://127.0.0.1:9456/`。

## 测试

```bash
npm test
```

## 玩法摘要

- 九张地图（等级逐步提高）：绿茵原野 → … → 冠军之路
- 击败训练家获得金币，并可捕捉其宝可梦；击败野生后直接捕捉
- 出战获胜获得经验；**8 级**一阶进化、**16 级**二阶进化、**24 级**超级进化
- 鼠标按住拖拽再松开丢球；需打中目标才会进入捕捉判定
- 商店可购买各种球与闪耀护符（闪光需护符）
- 头目有双红眼，能力更高、更难抓
- **100 级**后可用 3 个异次元果进入异次元。果子靠打败菊草叶，或在商店花 30 金币购买。你和 3 只电脑宝可梦一起挑战 200 级闪光超级裂空座
