# Spirit Hall maze tiles

Runtime tiles (`floor.png`, `wall.png`, `stairs.png`) are project-made 48×48 top-down stone tiles
styled after common CC0 dungeon packs researched for this feature:

- [Dungeon Crawl 32×32 / Project Utumno](https://opengameart.org/content/dungeon-crawl-32x32-tiles) (CC0)
- [32×32 Dungeon Tileset (stealthix)](https://opengameart.org/content/32x32-dungeon-tileset) (CC0)
- [Dungeon Tileset (HorusKDI)](https://opengameart.org/content/dungeon-tileset-4) (CC0)

Entity thumbnails on the map reuse existing Pokémon sprites under `assets/pokemon/`.
