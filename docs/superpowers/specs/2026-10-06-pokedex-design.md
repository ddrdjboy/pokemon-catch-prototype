# 图鉴按钮与列表设计

## 目标

在顶部栏右上角增加「图鉴」入口，打开后可浏览游戏内全部宝可梦图鉴列表（约 151 种），不区分是否捕捉。

## 决策摘要

| 项 | 选择 |
| --- | --- |
| 内容范围 | 全部种类直接可见（名字、精灵图、属性） |
| 条目深度 | 简洁列表；不可点击、无详情页 |
| 可用性 | 任意界面可打开（含对战、捕捉） |
| UI 形态 | 复用商店遮罩弹窗模式 |

## 入口与交互

- 在顶部栏 `.status` 内、「商店」按钮左侧增加 `#btn-dex`（文案：图鉴）。
- 点击打开图鉴弹窗；不切换当前 screen。
- 弹窗复用 `.shop-modal` 遮罩：点「关闭」或点遮罩空白处关闭。
- 打开图鉴不暂停对战逻辑（与商店一致）。

## 列表内容与数据

- 数据源：现有 `SPECIES`。
- 排序：按中文名 `localeCompare('zh')`。
- 每行：精灵图、中文名、属性标签（复用 `typeLabel` / `.tag.type`）。
- 标题显示数量，例如「图鉴（151）」。
- 不读写存档；不标记捕捉状态。

## 实现落点

- `index.html`：按钮 + `#dex-modal` 结构
- `css/game.css`：图鉴列表行样式
- `js/data.js`：导出纯函数 `listDexEntries`（排序后的展示数据）
- `js/game.js`：`openDex` / `closeDex` / `renderDex` 与事件绑定
- `tests/battle-catch.test.js`：覆盖 `listDexEntries` 排序与字段

## 非目标

- 捕捉进度 / 剪影解锁
- 详情页、筛选、搜索
- 进化链展示
- 独立全屏界面或抽屉

## 验收

1. 任意界面可见并可用「图鉴」按钮
2. 弹窗列出全部种类，含精灵图、中文名、属性
3. 关闭按钮与遮罩点击均可关闭
4. 现有 `npm test` 通过
