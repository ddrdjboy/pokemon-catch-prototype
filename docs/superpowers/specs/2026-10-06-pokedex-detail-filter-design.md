# 图鉴详情弹窗与属性筛选设计

## 目标

1. 图鉴列表支持按属性（系）单选筛选。
2. 点击列表行打开详情弹窗，展示完整种族信息。

## 决策摘要

| 项 | 选择 |
| --- | --- |
| 详情内容 | 大图、名字、属性、种族值、招式、捕捉率、进化信息 |
| 筛选 UI | 顶部芯片：全部 + 各属性，单选 |
| UI 形态 | 双层弹窗：列表在下，详情叠在上 |

## 列表筛选

- 标题下横向可滚芯片：`全部` + `listDexTypes()` 返回的属性（中文用 `typeLabel`）。
- 默认「全部」；点属性芯片筛选；点「全部」重置。
- 标题数量同步当前筛选结果。
- 关闭再打开图鉴时重置为「全部」。
- 列表行可点击，打开详情。

## 详情弹窗

- 第二层 `#dex-detail-modal`，z-index 高于图鉴列表弹窗。
- 展示：大精灵图、名字、属性标签、HP/攻/防/速、招式列表（`moves` 或回退 `move`）、捕捉率（百分比）、进化（有 `evolvesTo` 时显示「Lv.X → 名称」；`mega` 时显示超级标记）。
- 关闭：关闭按钮或点遮罩；关闭后回到列表，筛选状态保留。
- 关闭图鉴列表时若详情仍开着，一并关闭。

## 数据层

- `listDexEntries(species, { type })`：可选按 `type` 过滤后排序。
- `listDexTypes(species)`：去重后的属性 id 列表（稳定排序）。
- `getDexDetail(id, species)`：详情投影；无效 id 返回 `null`。

## 非目标

- 多选属性、搜索、进化链可点击跳转。
- 捕捉进度 / 剪影。

## 验收

1. 芯片可筛出对应属性，数量正确。
2. 点行弹出详情，字段完整。
3. 关详情回列表且筛选仍在；关图鉴后状态重置。
4. `npm test` 通过。
