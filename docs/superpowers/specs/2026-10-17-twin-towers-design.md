# 双子塔 2v2 挑战设计

## 目标

新增终局地图「双子塔」：每场同时对战 2 只 Lv.200 Boss，玩家同时派出 2 只宝可梦；胜利后从两只 Boss 中选 1 只捕捉。

## 决策摘要

| 项 | 选择 |
| --- | --- |
| 战斗模式 | 真·同时 2v2（速度排序行动） |
| Boss 组合 | ①苍响+藏玛然特 ②洛奇亚+凤王 ③拉帝亚斯+拉帝欧斯 ④故勒顿+密勒顿 |
| 等级 | 全部 Lv.200，固定 Boss（闪光） |
| 进图 | ≥2 只等级 **>100** + 消耗 1 个「双子钥匙」 |
| 钥匙 | 商店 5000 金币；可重复进图挑战 |
| 捕捉 | 每场只能选抓 1 只 |

## 地图与遭遇

- 地图 id：`twin_towers`，`twin: true`（特殊门槛，类似 `rift`）。
- 4 个 `dual: true` 野生遭遇点，各带 `foes: [{speciesId}, {speciesId}]`。
- 不强制清图锁定（可重复挑战）；进图扣钥匙，同一次停留内可点多个点。

## 战斗流程

1. 选战：从现役前 6 只中选 **2 只**存活宝可梦。
2. 场上左右各 2 只；每回合存活单位按速度行动。
3. 目标：优先打对面同槽位；该槽倒下则打另一只仍存活者。
4. 己方一只倒下且现役有后备 → 换人补位；可 1v2。
5. 敌方两只都倒下 → 胜；己方现役全灭 → 败。
6. 胜利后弹出两只 Boss，玩家选 1 只进入捕捉。

## 数据落点

- `js/data.js`：8 新物种、`TWIN_*` 常量、`trySpendTwinKey`、`TWIN_MAP`、并入 `MAPS`
- `js/battle.js`：`resolveDualTurn`
- `js/game.js`：进图门槛、双选出战、双位 UI、选抓
- `index.html` / `css/game.css`：双槽 UI、钥匙显示
- `assets/maps/twin_towers.png`、`assets/pokemon/{8}.png`
- `tests/battle-catch.test.js`：地图数、钥匙门槛、双打回合

## 非目标

- 招式手动选目标 UI
- Boss 专属 AOE 套件（沿用单招 `move`）
- 双打经验分摊公式以外的复杂规则（两只出战者均获经验即可）

## 验收

1. 选图可见「双子塔」；不足 2 只 >100 或无钥匙时提示并拦下
2. 商店可买双子钥匙（5000）
3. 4 组传说对均可开战，场上同时 2v2
4. 胜利后只能选抓 1 只
5. `npm test` 通过
