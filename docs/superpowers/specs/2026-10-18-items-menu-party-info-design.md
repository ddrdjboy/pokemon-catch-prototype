# 顶栏统一道具与队伍说明 toast

## 目标

把队伍区「道具」收到顶部菜单，全游戏共用一个道具弹窗。战斗中使用占用一回合。队伍排序说明不再常驻，改由标题旁的 ⓘ 以 toast 显示。

## 决策摘要

| 项 | 选择 |
| --- | --- |
| 入口位置 | 顶栏「商店」后，`#btn-items`，文案「道具」 |
| 弹窗形态 | 全局遮罩 `#items-modal`（方案 2：一套 UI） |
| 旧入口 | 去掉队伍区 `#btn-party-items` 与战斗栏 `#btn-item` |
| 场外 | 选道具 → 选队伍宝可梦 → 立即生效 |
| 战斗中 | 选道具 → `autoTargetForItem` 自动目标 → 占用一回合 |
| 不可用 | 战斗忙碌或当前不能用道具时禁用顶栏按钮；若仍点到，toast「现在不能用道具」 |
| 排序说明 | 删掉常驻 hint；`#btn-party-info` 在「我的宝可梦」旁；点了显示原文 toast |

## 入口与分流

- 顶栏任意界面可见。
- 非战斗：打开统一弹窗，第二步选目标宝可梦（沿用 `monAcceptsItem` / `applyItem`）。
- 战斗中且可行动：同一弹窗选道具后直接 `onUseItem`（沿用现有耗回合结算）。
- 用完或取消后关闭弹窗。关闭方式：取消按钮或点遮罩空白。

## 统一弹窗

- 不嵌在队伍栏或战斗栏内。
- 步骤：① 选道具；② 仅场外再选宝可梦。战斗中不二次选目标。
- 删除旧 DOM：`#item-panel`、`#bag-item-panel`、`#bag-target-panel`。逻辑收进新弹窗。

## 排序说明

- 删除文案常驻显示：`点卡排序。前 6 出场；收回进背包，上场回前 6。`
- `#btn-party-info`：小圆圈，文案 `i`。
- 点击后用页面级 `#app-toast` 显示上述原文，4000ms 后自动消失。样式参照现有 `.maze-toast`，挂在应用层，不限于迷宫。

## 数据落点

- `index.html`：顶栏按钮、ⓘ、`#items-modal`、`#app-toast`；移除旧面板与队伍道具按钮
- `css/game.css`：弹窗、ⓘ、toast
- `js/game.js`：统一打开/分流/toast；删除分散的 panel 开关

## 非目标

- 不改道具种类与效果
- 不改战斗自动选目标规则
- 不做道具详情页

## 验收

1. 顶栏商店旁有「道具」，任意界面可见
2. 场外：选道具 → 选宝可梦 → 生效
3. 战斗中：选道具 → 生效并占用一回合
4. 战斗栏不再单独有「道具」按钮
5. 排序说明只通过 ⓘ toast 出现
6. `npm test` 通过
