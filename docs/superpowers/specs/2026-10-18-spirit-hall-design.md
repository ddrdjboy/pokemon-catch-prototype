# 灵堂三层迷宫设计

## 目标

新增双子塔之后的终局场景「灵堂」：魔力宝贝式格子迷宫，三层随机生成；路上有游荡野生碰撞开战；每层楼梯处为固定 1v1 头目 Boss；底层为大 Boss。全灭踢出，下次从第 1 层重新开始。

## 决策摘要

| 项 | 选择 |
| --- | --- |
| 名称 / id | 灵堂 / `spirit_hall` |
| 探索 | 独立 `maze` 屏；四向格子移动；每层随机房间+走廊，全连通 |
| 解锁 | 至少通关双子塔 1 次（`twinCleared`）；之后免费反复进 |
| 游荡怪 | 站桩；玩家踩格开战；可抓 |
| Boss | 1 层伊裴尔达尔 Lv.225 → 2 层哲尔尼亚斯 Lv.250 → 3 层基格尔德 Lv.300 |
| Boss 战斗 | 全部强化 1v1 闪光头目；可抓 |
| 失败 | 全灭清 `mazeRun`，退回选地图；下次从第 1 层重新随机 |
| 退出 | 主动退出 = 放弃当次探索（进度不保留） |

## 场景流程

1. 选地图点「灵堂」→ 检查 `twinCleared`；未解锁则提示并拦下。
2. 通过后进入 `maze` 屏，生成第 1 层，玩家出生在入口格。
3. 走路；踩游荡怪 → 现有野生战斗 → 胜可抓、怪从层上移除；败则结束本次 run。
4. 踩本层楼梯/祭坛格 → 触发该层 Boss（同一次 run 内每层楼梯只打一次；已胜则可直接下楼）。
5. Boss 胜 → 可抓 → 进入下一层（重新随机生成）。
6. 第 3 层基格尔德胜利并处理捕捉后 → 通关，回选地图并提示胜利。

## 运行时与存档

**当次探索（不写入存档整层迷宫）：**

```text
mazeRun = {
  floor: 1 | 2 | 3,
  grid: Cell[][],       // wall | floor | stairs
  player: { x, y },
  roamers: [{ id, x, y, speciesId, level, ... }],
  floorBossDefeated: bool,
}
```

**持久化新增：**

- `state.twinCleared`：任意 `twin_towers` 遭遇首次胜利后置 `true`。
- 抓到的宝可梦仍进现有 `party` / 背包字段。

## 迷宫生成与移动

- 算法：房间 + 走廊，保证全连通；每层进层时重掷。
- 尺寸：约 13×13～17×17 可行走区域（含墙更大）。
- 每层放置：出生点、楼梯格（远离出生点）；游荡怪 6～10 只，不与出生/楼梯重叠。
- 移动：方向键 / WASD + 屏幕方向按钮；一步一格；撞墙不动。
- 首版：整层可见、无迷雾；游荡怪不 AI 追击。
- UI 顶栏：层数、简况、退出。

## 遭遇与等级

**楼梯 Boss（固定）：**

| 层 | speciesId | 名 | 等级 |
| --- | --- | --- | --- |
| 1 | `eternatus` | 伊裴尔达尔 | 225 |
| 2 | `xerneas` | 哲尔尼亚斯 | 250 |
| 3 | `zygarde` | 基格尔德（完全体） | 300 |

三者需新增物种与立绘；遭遇为 `kind: 'wild'`，固定 `boss` + `shiny`。基格尔德按完全体造型与种族值做大 Boss。

**游荡野生等级带（从现有 SPECIES 抽「灵堂气质」池）：**

- 1 层：约 Lv.180–200
- 2 层：约 Lv.200–220
- 3 层：约 Lv.220–240

## 非目标

- 游荡怪主动追击 AI
- 迷雾、宝箱、陷阱
- Boss 专属多段招式套件（沿用单招 `move`）
- 迷宫进度持久化
- 入场消耗道具

## 验收

1. 未通关双子塔时灵堂不可进，有明确提示
2. 通关后可免费进；每次第 1 层随机且全连通
3. 四向走路；踩游荡怪开战，胜可抓，败踢出并从第 1 层重来
4. 楼梯依次触发伊裴尔达尔 225、哲尔尼亚斯 250、基格尔德 300；打完第 3 层通关
5. 主动退出放弃当次；`npm test` 通过
