# 最终形态与传说技能设计

## 目标

给已经是终点的宝可梦各设计 3 个技能：两个攻击招、一个功能招。本文件只定技能表。战斗结算、选招界面都不在这次范围内。

## 决策摘要

| 项 | 选择 |
| --- | --- |
| 范围 | 超级终点、传说、没有超级的终点强者。中间形态和未完成进化链的初阶不做 |
| 结构 | 招牌套装：本系主力 + 相克覆盖 + 一个功能招 |
| 功能效果 | 全游戏共用三种：回复、加攻、加防 |
| 相克依据 | 游戏内 `TYPE_CHART`（1.5 倍 / 0.5 倍），不是官方 2 倍 / 无效表 |
| 现有招牌 | 主力沿用该只现在的招式名、威力和属性 |

## 范围

共 41 只。

- 26 只超级终点（含超级裂空座）
- 8 只传说：苍响、藏玛然特、洛奇亚、凤王、拉帝亚斯、拉帝欧斯、故勒顿、密勒顿。超级裂空座算在超级里，不重复计数
- 7 只没有超级、但已经是终点的：路卡利欧、烈咬陆鲨、班基拉斯、巨金怪、波克基斯、飞腿郎、快拳郎

喷火龙、妙蛙花这类还会超级进化的形态不做。火球鼠、木守宫这类图鉴里没有后续进化的初阶不做。

## 三格规则

1. **主力**：保留现在的招牌招。威力不动。
2. **覆盖**：属性按下面的相克表选，名字用这只真正会用的招。威力 = 主力威力 − 15。
3. **功能**：不造成伤害。有名的功能招优先；没有时，攻击高于防御用加攻，防御高于攻击用加防，攻防相同或偏耐久用回复。

功能只有三种效果，每场战斗生效一次：

| 效果 | 规则 | 常见招名 |
| --- | --- | --- |
| 回复 | 回复最大生命的 50% | 光合作用、自我再生、羽栖、睡觉、治愈波动 |
| 加攻 | 攻击变为 1.5 倍 | 剑舞、龙之舞、冥想、诡计、健美、充电 |
| 加防 | 防御变为 1.5 倍 | 铁壁 |

游戏里只有一条攻击数值，所以冥想、诡计、充电都记成加攻。

## 覆盖属性

按攻击方本系在 `TYPE_CHART` 里的 0.5 倍对象来选。优先能同时打中至少两个半倍对象的属性。这只没有该属性的招牌招时，改用它真正会的、至少打中一个半倍对象的招，并在表里注明。

| 本系 | 半倍对象 | 覆盖属性 | 打中 |
| --- | --- | --- | --- |
| 火 | 水、岩石、龙 | 草 | 水、岩石 |
| 水 | 水、草、龙 | 冰 | 草、龙 |
| 草 | 火、虫、毒、龙、飞行、钢 | 地面 | 火、毒、钢 |
| 电 | 草、电、龙、地面 | 冰 | 草、龙、地面 |
| 岩石 | 地面、格斗、钢 | 地面 | 钢 |
| 虫 | 火、毒、幽灵、飞行、格斗、钢、妖精 | 地面 | 火、毒、钢 |
| 格斗 | 虫、毒、超能、幽灵、飞行、妖精 | 岩石 | 虫、飞行 |
| 超能 | 超能、钢、恶 | 格斗 | 钢、恶 |
| 幽灵 | 一般、恶 | 格斗 | 一般、恶 |
| 龙 | 钢、妖精 | 地面或火 | 钢 |
| 冰 | 火、水、冰、钢 | 地面 | 火、钢 |
| 钢 | 火、水、电、钢 | 地面 | 火、电、钢 |
| 妖精 | 火、毒、钢 | 地面 | 火、毒、钢 |

岩石系没有能同时打中两个半倍对象、又符合招牌的招。隆隆岩、班基拉斯用地震，只打中钢。格斗系若这只更以恶系招闻名（路卡利欧、藏玛然特），改用恶，打中超能和幽灵。

## 例外

- **洛奇亚**：现有招牌「空气爆破」是飞行，不是超能。主力保留空气爆破。覆盖改为超能「精神强念」，补上本系攻击。
- **超级裂空座**：现有招牌「飞冲升天」是飞行。主力保留。覆盖用龙系「龙星群」。现在的四招组（龙星群、飞冲升天、逆鳞、空气斩）在实现时收成这三格。空气斩的群体效果不保留。
- **超级闪焰王牌**：不会草系招。覆盖用「飞膝踢」（格斗），只打中岩石。
- **超级沙奈朵、波克基斯**：地面能打中三个半倍对象，但沙奈朵用它会的「真气弹」（格斗，打中钢），波克基斯用「喷射火焰」（火，打中钢）。
- **超级暴鲤龙**：防御高于攻击，但招牌功能是龙之舞，记为加攻。
- **超级刺龙王**：攻防相同，招牌功能是龙之舞，记为加攻。
- **凤王、妙蛙花、霸王花、大竺葵**：攻击或攻防接近，但招牌功能是回复，不用加攻或加防。
- **班基拉斯**：防御高于攻击，但招牌功能是龙之舞，记为加攻。

## 数据形状（实现时）

每只终点增加 `moves` 数组，三项顺序固定为主力、覆盖、功能。`move` 继续保留，并等于主力，这样现有只读 `move` 的战斗逻辑行为不变。

```js
moves: [
  { name: '爆炸烈焰', power: 89, type: 'fire' },
  { name: '日光束', power: 74, type: 'grass' },
  { name: '剑舞', power: 0, type: 'normal', effect: 'atk' },
]
```

`effect` 只允许 `heal`、`atk`、`def`。攻击招不写 `effect`。

## 不做

- 不改中间形态和初阶的技能
- 不在这次改 `resolveTurn` 的选招或功能结算
- 不把官方 2 倍 / 无效表写进 `TYPE_CHART`
- 不保留超级裂空座的群体招「空气斩」
