# 队伍宠物「详情」按钮设计

## 目标

在「我的宝可梦」点击宠物后的操作菜单中，增加「详情」按钮；点击后弹出该宝可梦的详情信息（个体状态 + 图鉴信息）。

## 决策摘要

| 项 | 选择 |
| --- | --- |
| 入口位置 | 队伍卡片 popover 最上方（「详情」为第一项） |
| 弹框形态 | 复用现有 `#dex-detail-modal` |
| 内容范围 | 个体信息 + 图鉴信息（方案 C） |
| 图鉴入口 | 行为不变：仅显示图鉴信息，无个体区块 |

## 交互

1. 点队伍卡片 → 打开现有 `party-popover`（左移 / 右移 / 收回或上场）。
2. popover 顶部新增「详情」按钮。
3. 点「详情」→ 关闭 popover，打开详情弹框，并传入该只 `mon`。
4. 关闭方式与现有一致：关闭按钮或点遮罩。
5. 从图鉴列表打开详情时不显示个体区块。

## 弹框内容（自上而下）

1. 标题：宝可梦名字  
2. 精灵大图；若有战斗帧则保留「播放动画」  
3. **个体信息**（仅队伍入口）：  
   - 等级、HP（当前/上限）  
   - 实际能力：攻 / 防 / 速  
   - 经验：当前 / 升级所需（`xpToNext(level)`）  
   - 标签：闪光（若有）、倒地（`hp <= 0`）  
4. **图鉴信息**（始终）：属性、超级标签、种族值、招式、捕捉率、进化说明（与现有 `renderDexDetail` 一致）

## 实现要点

- `buildPartyPopover`：在现有按钮之前插入「详情」。
- 扩展 `openDexDetail` / `renderDexDetail`：可选传入队伍 `mon`；有则渲染个体区块。
- 新增薄封装 `openPartyDetail(mon)`：关 popover 后打开带个体信息的详情。
- `css/game.css`：个体区块少量样式，复用 `.dex-detail` / `.tag`。
- 不新增 HTML 弹框节点。

## 非目标

- 在详情弹框内改名、放生、排序等操作。
- 独立的 `party-detail-modal`。
- 卡片内嵌展开（非弹框）方案。

## 验收

1. 队伍卡片 popover 第一项为「详情」。
2. 点「详情」打开弹框，可见个体信息与图鉴信息。
3. 图鉴列表点进详情仍无个体区块。
4. 关闭弹框 / 点遮罩行为正常；popover 已关闭。
5. `npm test` 通过。
