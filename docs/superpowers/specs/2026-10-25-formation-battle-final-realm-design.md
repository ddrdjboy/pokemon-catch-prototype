# 魔力编队战（终焉领域试点）Design

**Date:** 2026-10-25  
**Repo:** `redfish`（`pokemon-catch-prototype`）  
**Status:** Approved — 方案 2（双模式）+ 终焉领域试点

## Goal

提升对战场观感，向魔力宝贝靠拢：左右编队舞台、分层场景、底部指令栏；并让全队参战、可为每只宠配置普攻/技能。  
首轮只在 **终焉领域**（`final_realm`）试点，其它地图保持经典 1v1。

## Decisions

| 项 | 选择 |
|----|------|
| 整体策略 | 双模式并存：经典 1v1 保留；编队战按地图开关 |
| 试点入口 | 仅 `final_realm`（配置 `battleMode: 'formation'`） |
| 气质 | 魔力宝贝：站位 + 场景/UI 质感；立绘沿用宝可梦素材（投影/朝向） |
| 上场规则 | 我方未倒地前 5 只站场；敌方该遭遇阵容一次摆上（上限 5） |
| 操作 | 每回合我方存活单位依次下指令：攻击 / 技能 / 道具 / 防御 |
| 结算 | 双方指令收集完后按速度排序逐个出手；沿用现有伤害与招式效果 |
| 配招 | 每只宠 loadout：普攻 1 + 技能最多 3；池子 = `speciesMoveList` |
| 不做（本轮） | 全局开关、灵堂编队战、站位攻防修正、同时结算、魔力原作数值重写 |

## Architecture

| 层 | 职责 |
|----|------|
| 地图配置 | `final_realm.battleMode = 'formation'`；遭遇入口读标记分流 |
| `js/formation-battle.js` | 纯逻辑：指令结构、速度排序结算、防御标记、目标重定向、胜负 |
| `js/battle.js` / `battle-moves.js` | 继续提供 `calcDamage`、`applyMoveEffect`、`speciesMoveList` 等；不改经典 `resolveTurn` 行为 |
| `js/game.js` | 路由遭遇 → 编队 UI；点名下指令；调用 formation 结算与演出 |
| 存档 / 队伍 | 每只宠可选 `loadout`；缺省回填 |
| `css/game.css` + HTML | `#screen-formation-battle`（或 battle 屏 `data-mode="formation"`）：左右舞台、指令栏、血条 |

经典 1v1 代码路径保持默认；编队战为旁路，避免两套逻辑缠死在同一函数里。

## Screen & layout

- **舞台**：左侧我方斜向编队，右侧敌方；背景用终焉领域地图图（可加暗角/地面阴影层）。
- **单位**：立绘 `image-rendering: pixelated`、椭圆投影、朝向内侧；当前点名单位高亮。
- **HUD**：头顶短血条 + 名；可选小型状态（防御中）。
- **底部指令栏**：攻击 / 技能 / 道具 / 防御（魔力风面板按钮）。
  - **攻击**：该宠 `basicMove` → 选敌方存活目标。
  - **技能**：仅显示 loadout 技能 → 选招 → 选目标（效果类招式可不选敌方目标）。
  - **道具**：接现有战斗可用道具；若无可用则禁用。
  - **防御**：不选目标；本回合受击伤害 ×0.5。
- **点名顺序**：我方存活单位按站位序号（队伍顺序）依次下指令。

## Turn resolution

1. 我方全部存活单位完成指令。  
2. 敌方 AI：每只存活单位选攻击或技能（低血可防御 / 治疗技，复用 `chooseFoeMove` 思路扩展到多目标）。  
3. 合并行动队列，按 `spd` 降序（同速随机）依次执行。  
4. 行动时若目标已倒下：改打该侧下一只存活单位；若无目标则跳过。  
5. 选了防御的单位在本回合结算期间受伤 ×0.5；整轮行动全部结算完后清除全体防御标记。  
6. 一侧 HP 全为 0 → 胜/负；野生胜后走现有捕捉流。

## Loadout（配招）

存档字段（示意）：

```js
mon.loadout = {
  basicMoveName: '撞击',      // 或稳定 id；实现时与物种 moves 对齐
  skillMoveNames: ['电击', '定身'], // 最多 3
};
```

- 可选池：`speciesMoveList(SPECIES[mon.speciesId])`。  
- 缺省：普攻 = 列表第一招；技能 = 其余截断到 3。  
- UI：队伍详情「配置技能」；非法/过期名称读档时回退缺省。  
- 经典 1v1 可不读 loadout（仍用现有整表选招），避免双模式互相干扰。

## Encounter routing

- 进入地图遭遇时：若 `map.battleMode === 'formation'` → `startFormationBattle(...)`。  
- 否则 → 现有 `startBattle` / 双打等逻辑不变。  
- 逃跑：野生编队战允许逃跑；训练家战与经典规则对齐（经典不可逃则编队也不可逃）。

## Out of scope

- 其它地图 / 灵堂启用编队战（仅预留配置位）  
- 玩家设置里的全局「经典 / 编队」开关  
- 站位前后排伤害修正、同时出手结算  
- 重画全部宝可梦立绘或替换为魔力原作造型  
- 改捕捉判定公式  

## Verification

1. 非终焉领域：对战 UI 与流程与现在一致。  
2. 终焉领域：遭遇进入编队舞台 + 四指令栏。  
3. 可为不同宠配置普攻/技能；战斗「技能」只显示已配置项。  
4. 全队下指令后按速度结算；防御明显减伤；全灭正确胜负。  
5. 野生可进入捕捉；`npm test` 通过（含 formation 结算单测）。
