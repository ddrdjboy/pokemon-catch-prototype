# 幽灵冥界阵型挑战设计

## 目标

新增终局地图「幽灵冥界」：一场战同时上场敌方 3 Boss + 7 小怪（两排站位），我方 1 只出战 + 4 只随机 AI 助战；玩法接近魔力宝贝（前排挡后排 + 全场速度排队出手）。**本玩法仅用于本图，不扩散到其他地图。**

## 决策摘要

| 项 | 选择 |
| --- | --- |
| 地图名 / id | 幽灵冥界 / `ghost_nether` |
| 战斗模式 | `formation`（新；仅本图入口调用） |
| 敌方 | 前排 5 小怪 + 后排（2 小怪 + 3 Boss），共 10 只同场 |
| 三 Boss | 改·达克莱伊、改·克雷色利亚、改·露奈雅拉（均 Lv.200，`boss: true`，闪光） |
| 胜利 | 清场：10 敌全部倒下 |
| 我方 | 玩家选 1 只出战 + 固定池无放回随机 4 只 AI 助战（不入队） |
| 进图 | ≥2 只等级 **>100** + 消耗 1 个「冥界符」 |
| 冥界符 | 商店 5000 金币；可重复挑战 |
| 捕捉 | 胜利后三巨头各可尝试捕捉（沿用 Boss 捕捉倍率）；小怪不开放捕捉 |

## 地图与遭遇

- 地图 id：`ghost_nether`，标记 `nether: true`（特殊门槛，类似 `rift` / `twin`）。
- 一张场景图 + **单个**战斗标记（一局定胜负）。
- 遭遇模板形如：
  - `formation: true`
  - Boss 槽 `level: 200`；前排小怪 `level: 160`；后排小怪 `level: 180`
  - `rows: { front: [...], back: [...] }`，每槽含 `speciesId`、是否 `boss`
- 不强制清图锁定。与双子塔对齐：**进图扣 1 次冥界符，同图停留内重复开战不另扣**。

## 站位与出手规则

### 布局

```
后排:  [小怪] [改·达克莱伊] [改·露奈雅拉] [改·克雷色利亚] [小怪]
前排:  [小怪] [小怪] [小怪] [小怪] [小怪]
我方:  [助1] [助2] [玩家] [助3] [助4]   （单排，无前后）
```

后排三 Boss 居中：露奈雅拉居中坦克/AoE，达克莱伊与克雷色利亚分居两侧。

### 锁定

- 默认只能选前排仍存活单位。
- 前排清空后，后排全部可被锁定。
- 例外：带 `pierce: true` 的技能可无视前排锁定后排（威力或 PP 略弱，避免开局秒后排）。
- Boss AoE 可打击我方全体（玩家 + 助战）。

### 出手顺序

- 每回合开始：收集场上所有存活单位（最多 1+4+10），按 `spe` 降序排队，依次行动。
- 玩家回合：选手动技能 + 合法目标。
- AI 助战 / 敌人：优先攻击可锁定目标中 HP 比例最低者；治疗技优先奶己方 HP 比例最低者。

### 胜负

- 胜：敌方 10 只全灭。
- 败：玩家出战宝可梦倒下（助战可先全灭；助战倒下不直接判负）。
- 伤害公式沿用 `calcDamage`；Boss 仍用 `BOSS_STAT_MULT`。

## 敌人与助战

### 三 Boss 定位

| 显示名 | speciesId（建议） | 定位 |
| --- | --- | --- |
| 改·达克莱伊 | `remake_darkrai` | 高攻；穿位暗技；睡眠/干扰 |
| 改·克雷色利亚 | `remake_cresselia` | 高防；治疗/护盾后排 |
| 改·露奈雅拉 | `remake_lunala` | 血厚；群体打击；半血后「开冥门」增强 |

三者均为新增物种条目（图鉴名带「改·」前缀），立绘可基于对应传说精灵改色/加幽冥特效。

### 7 只小怪

- 固定阵容（不随机），幽灵/恶系为主，优先复用现有物种并调等级与是否 boss=false。
- 前排 5：肉盾与骚扰。
- 后排 2：贴在 Boss 两侧的远程骚扰。
- 具体 species 列表实现阶段在 `GHOST_NETHER_MINIONS` 常量中写死，并在测试中锁定槽位数 7。

### 助战池

- 固定池 8 只模板（龙/超能/钢等均衡），一律 Lv.100（对齐异次元助战）。
- `createGhostNetherAllies()`：无放回抽 4 只；仅本场有效，不入 `party`。
- 仅 `ghost_nether` 开战路径调用。

## 战斗流程

1. 选图「幽灵冥界」→ 校验 2 只 >Lv.100 且持有冥界符 → 扣 1 符进图。
2. 点唯一标记 → 从现役中选 **1** 只存活宝可梦出战。
3. 系统抽取 4 助战 → 进入 `formation` 战。
4. 按速度排队行动；目标选择遵守前后排锁定与穿位例外。
5. 敌方全灭 → 胜；弹出三 Boss 列表，玩家可**依次**对仍想抓的 Boss 尝试捕捉（可跳过某一只；小怪不可抓）。
6. 玩家倒下 → 败；可买符再挑战。

## UI

- 选图卡片：暗色/幽冥风（可参考双子塔卡片变体），未满足条件灰显并提示。
- 战斗（仅本图）：
  - 敌方上排后排、下排前排，各 5 槽；Boss 槽加大 + 红眼 Boss 标记。
  - 我方主槽 + `#ally-row` 扩展为 4 助战芯片。
  - 不可锁后排时后排半透明；穿位技可选中后排并高亮。
  - 简短「下一动：xxx」提示即可，不做完整时间条。
- 商店与顶栏：冥界符数量显示（对齐双子钥匙）。

## 范围约束（重要）

- `formation`、两排 UI、穿位规则、随机 4 助战 **只**挂在 `ghost_nether`。
- 其他地图继续：1v1 / 异次元 `squad` / 双子塔 `dual`，行为不变。

## 非目标

- 把阵型战斗做成通用地图生成器或可配置关卡编辑器。
- 我方前后排站位。
- 完整魔力宝贝式职业/怒气/忠诚系统。
- 小怪捕捉、助战永久入队。
- 多标记多波连战（本图单点一战）。

## 验收

1. 选图可见「幽灵冥界」；不足 2 只 >100 或无冥界符时提示并拦下。
2. 商店可买冥界符（5000）；顶栏可显示持有数。
3. 开战为我方 1+4 vs 敌方两排共 10；仅本图出现该 UI/规则。
4. 前排未清空时默认无法锁定后排；穿位技可打后排。
5. 全场按速度排队出手；清场才算胜利。
6. 胜利后可对三 Boss 尝试捕捉；助战不入队。
7. `npm test` 通过；既有 1v1 / rift / dual 测试不受影响。
